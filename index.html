GitHub Sync — Admin Tool

Central na admin tool para sa lahat ng GitHub-based na pag-sync — file publishing, community server list, at admin settings backup. Ito na lang ang gamitin, hindi na naka-built-in sa app mismo.
⚠️ Ang token ay ginagamit lang sa browser session mo — hindi ito naise-save o nagpapadala kahit saan maliban sa api.github.com. Isara ang tab na ito pagkatapos gamitin kung shared o public na computer. Gumamit ng fine-grained PAT na naka-limit lang sa isang repo, "Contents: Read and write" lang.
Settings → Developer settings → Fine-grained tokens → grant "Contents: Read and write" sa target repo lang.
1) I-paste ang totoong token sa taas. 2) Ilagay ang passphrase. 3) Pindutin ito — mapapalitan ng encrypted blob ang Token field, ligtas mo na 'yong i-save sa file. Ide-decrypt na lang ito automatic (gamit ang passphrase) tuwing gagamitin ang mga button sa ibaba.
Kokopyahin ang laman ng Token field kung ano man ang nakalagay dito ngayon (naka-encrypt na blob kadalasan pagkatapos mag-restore) — hindi ito ide-decrypt, direktang kopya lang ito papunta sa clipboard mo.
Ise-save ang naka-encrypt na token (gamit ang Token Passphrase sa itaas) sa parehong GitHub file, sa ilalim ng sarili nitong key — hindi ito nakikita sa "servers" list. Sa ibang browser/device, i-restore mo lang gamit ang parehong Owner/Repo/Path + Token Passphrase (token mismo hindi na kailangan kung public ang repo) — hindi mo na kailangang kopyahin nang manual ang buong encrypted blob.

VPS Self-Service Settings

Ito yung parehong VPS root login + self-service settings na nasa app (VPS Self-Service section). Naka-encrypt (gamit ang Token Passphrase sa itaas) bago i-store sa GitHub file — sarili nitong key din, hiwalay sa token at sa server list.
Kailangan ng Token Passphrase sa itaas para ma-encrypt/ma-decrypt. Ise-save sa ilalim ng sariling "vpsBackup" key sa parehong GitHub file — hindi ito nakikita sa "servers" list, at hiwalay ito sa Token Backup at sa buong Admin Settings Backup (kung meron man).

🔐 Backup / Restore LAHAT ng Credentials

Isang pindot lang para ma-imbak (o mabalik) ang Token AT VPS settings nang sabay — parehong naka-encrypt gamit ang Token Passphrase sa itaas, sa parehong GitHub file.
Backup: kukunin ang laman ng Token field (i-e-encrypt kung plain pa) at ang VPS IP/Port/User/Pass/Days/Enabled fields, i-e-encrypt gamit ang Token Passphrase, tapos isang commit lang ang gagawin sa GitHub para sa dalawa. Restore: babalik ang naka-encrypt na token sa Token field (hindi awtomatikong ide-decrypt — gamitin na lang ito nang direkta), at ide-decrypt agad ang VPS fields pabalik sa mga input sa itaas.
